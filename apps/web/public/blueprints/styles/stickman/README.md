# Stickman visual style samples

Seven AI-generated samples, one per suggested Visual style on the Stickman
Blueprint's video flows (`x-example-images` on the `visual_style` run input).
They show what each style direction looks like; they are not outputs of a
Workspace run and are not customer content.

Generated on 2026-10-23 with OpenRouter `google/gemini-3-pro-image-preview`, using
the Blueprint's default Stickman character as the reference image and one shared
scene (the character waving beside a potted plant) so only the style differs.
No text, logos or third-party marks. Each 1376 × 768 PNG was LANCZOS-resized to
640 × 357 and encoded as WebP quality 80.
