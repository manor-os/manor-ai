# Song style covers

Twenty-four AI-generated covers, one per suggested song style template
(`x-example-images` on a song Flow's `style` run input, same order as its
`examples`). They show the mood of each style; they are not outputs of a
Workspace run and are not customer content.

Generated on 2026-10-29 through the Vercel AI Gateway with
`google/gemini-3-pro-image-preview`, one shared prompt ("premium music streaming
playlist cover, cinematic and vivid … a single unmistakable hero subject that
instantly tells the music genre") plus a scene per style. No text, logos,
third-party marks or visible faces. Each 1376 × 768 PNG was center-cropped to
16:9 (letterbox bars removed), LANCZOS-resized to 640 × 360 and encoded as
WebP quality 82.
