Staff-level 排障模板

I would first determine the blast radius and check the golden signals: latency, traffic, errors, and saturation.
Then I would correlate with recent deploys, config changes, dependency incidents, and traffic spikes.
At the host level, I would check CPU, memory, disk, and network using top, free, df, iostat, ss, curl, dig, and journalctl.
If user impact is high, I would mitigate first through rollback, scaling, feature flag disablement, or failover.
After mitigation, I would continue root cause analysis and add prevention such as alerts, rate limits, circuit breakers, capacity planning, or runbook automation.
