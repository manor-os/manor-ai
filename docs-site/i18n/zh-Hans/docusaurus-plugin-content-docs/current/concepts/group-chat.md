# 群聊

群聊让成员和 AI Agent 在同一段对话中协作。群聊可归属于个人或当前公司，但加入群聊**不会**自动获得公司成员身份或[工作区](workspaces-knowledge.md)访问权限。

## 创建群聊与邀请成员

1. 打开**聊天**，新建消息并添加一位或多位收件人。
2. 选择**创建群聊**，填写群名称，选择归属为**个人**或**当前公司**后创建。
3. 后续邀请可从**群聊详情 → 成员 → 邀请**发起。

所有受邀人，包括已有 Manor 账号的用户，都会通过邀请人连接的 SMTP、Gmail 或 Outlook 账号发送邀请邮件。发信邮箱与 eSign 共用，统一在 **Integrations → For Agents → 邮箱** 中打开 SMTP、Gmail 或 Outlook 集成卡片，在账号菜单中选择“设为默认”；邀请和 eSign 自动使用该邮箱。已验证受邀邮箱的 Manor 用户还会收到站内邀请，同意后才加入；尚未注册或尚未验证邮箱的用户需按需注册、验证受邀邮箱并同意后才加入。如果未连接发送邮箱或邮件发送失败，邀请仍会创建，可复制页面上的邀请链接直接分享。所有群成员都可以邀请他人，查看、取消或重新生成自己发出的待处理邀请；群主和管理员可管理全部待处理邀请。新成员只能看到加入后的消息，邀请不会授予公司或工作区权限。

## 消息、提醒与文件

输入 `@` 提及成员或 AI Agent。你可以发送图片等附件、针对某条消息回复、添加表情回应，以及撤回自己的消息。可以在**消息**页搜索群消息；聊天侧栏显示未读数。到**群聊详情 → 设置**可为自己开启或关闭提及与回复提醒。

**文件**页集中显示本群分享的文件，包括 AI 生成的文件。生成文件也存放在 Knowledge 中 **Group chat files** 下以群名称和 ID 命名的私有子文件夹。可以预览、下载；有删除权限时也可移除群文件。移除群文件不会删除原始 Knowledge 文档；撤回消息也不会单独移除已分享的文件。

## 与 AI 协作

群主或管理员可在**群聊详情 → AI**添加可用的 [Agent](agents.md)。任何成员都可以 `@` Agent 请求回复、针对本次请求联网搜索，或让 AI 分析自己刚发送的附件。群内 Agent 使用本群对话，不继承个人 Knowledge、私有工作区文件或集成凭据。

群主可开启**AI 处理群文件**。开启后，群主或管理员可以让 AI 读取、生成和管理**本群**文件，包括文档、演示文稿、电子表格、图片、音频和视频；这类群文件操作不再逐次申请审批。完成的文件会出现在群里，此开关不会开放其他群或私有数据。工作区 Agent 的回复仍可能依照[治理规则](hitl-governance.md)，由同时具备群管理和工作区审批权限的人批准。

群主可以设置管理员或解散群聊；管理员可以移除普通成员；所有成员都可以邀请他人，非群主可以退出群聊。
