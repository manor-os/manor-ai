# 歌词视频（Lyric video）

适用：歌词随演唱逐词出现的动态排版视频，用于歌曲发布、副歌片段、K 歌传播。默认：9:16、45s、无配音（声音为歌曲本身）。

## 结构与节拍
45s 通常截取"主歌末 + 预副歌 + 副歌"：
1. 0–2s 开场：歌名 + 演唱者（首帧可读），背景随前奏进入。
2. 主歌：每行歌词完整出现后，当前演唱的词被强调；一行唱完后整行淡出或上移。
3. 副歌：排版能量提升（更大字号、更强的强调动作、背景随重拍变化），副歌第一个字落在副歌第一个重拍上。
4. 最后 2–3s：歌名 + 演唱者 + 版权信息，静止 ≥ 1.5s。
换行按乐句：一行 = 一个乐句，不在乐句中间断行。

## 视觉规则
- 当前词强调：颜色或字重变化（例：白 → 强调色），强调开始 = 该词开唱时间；未唱的词 50–60% 不透明度。
- 一屏 1–2 行歌词；中文每行 ≤ 12 字，英文每行 ≤ 6 词。
- 9:16 安全区：歌词避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520）。
- 字号：主歌 ≥ 64px，副歌 ≥ 80px；字体 ≤ 2 种，默认 Noto Sans CJK SC / Lato，或用户提供的字体文件（放进 `assets/`）。
- 背景简单，运动幅度小于文字；可按节拍做轻微脉冲。
- 歌词文字以用户提供的版本为准，包括标点与分行。

## 制作路线
1. 输入：歌曲音频 + 用户提供的歌词（必填）。确认用户有权发布该歌曲与歌词。`probe_media` 歌曲时长与选段。
2. 时间：`transcribe_video` 转写演唱，得到分段时间戳；把转写结果与用户歌词逐句对齐，只用转写的时间、不用转写的文字。段内逐词时间按字数比例插值。返回 timestamps_available=false 或某段转写失败（伴奏太响、拖腔、和声）时，按 BPM 计算节拍网格，人工设定该段时间并在 CANVAS 标注"人工"。
3. 在 CANVAS 写歌词时间表：行号、行起止时间、每词开始时间、时间来源（转写 / 人工）、对应乐句。
4. 在 `video_edit`（HyperFrames）中逐词排版，每个词一个 span；强调动画挂在 paused timeline 上，是 t 的纯函数，不用实时时钟、不用无种子随机。
5. 背景：纯排版背景，或用户提供的画面 / `generate_image` 生成的背景图（标注为生成）。
6. 歌曲本身已混好音：只在需要时 `normalize_audio_loudness` 到平台目标，再 `video_edit(operation="push_assets")`，单位增益放置。
7. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取每行开唱时刻、副歌第一拍、最后一帧；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 直接用转写文字上屏：错字、漏字、同音字，歌词以用户版本为准。
- 强调提前：词还没唱就变色，像卡拉 OK 抢拍。
- 拖腔长音只给一个词的时间，下一词出现太早。
- 断行切在乐句中间，读起来与旋律打架。
- 未确认版权：歌词与歌曲都受版权保护，只处理用户有权使用的作品。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps，时长与选段一致。
- [ ] 成片帧（`render_frame_samples`）中的歌词文字与用户提供的歌词逐字一致（含分行）。
- [ ] 抽 3 行：对每行开头取 ±2s 窗口对成片调用 `transcribe_video(input_path, start_seconds, end_seconds)`，返回分段起点与画面该行出现时间偏差 ≤ 0.5s（timestamps_available=false 时标为"未测量"，人工试听确认）。
- [ ] 目视判断同一组帧：歌词都在 x 60–940、y 220–1520 内，一屏不超过 2 行。
- [ ] 副歌第一字出现时间与按 BPM 网格计算的副歌第一个重拍偏差 ≤ 1 帧。
- [ ] 最后一帧含歌名与演唱者，静止 ≥ 1.5s。
- [ ] `analyze_audio`（成片 MP4）：整合响度在 −20 到 −14 LUFS，true peak ≤ −1 dBTP，选段首尾无突兀截断。
