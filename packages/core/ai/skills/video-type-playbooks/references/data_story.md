# 数据图表动画（Data story）

适用：把用户提供的一组数字或一张表做成会动的故事：计数、柱状、折线、对比。默认：16:9、30s、无配音。

## 结构与节拍
1. 0–3s 问题：一句话提出这组数据回答的问题（例："过去 5 年门店数怎么变？"），首帧即可读。
2. 3–8s 主数字：一个 count-up 落定在用户数据的确切值上，配单位和时间范围。
3. 8–20s 主图：柱状 / 折线 / 对比，逐项随讲述出现；每个数据点出现后停留 ≥ 1s 才动下一个。
4. 20–26s 结论：高亮 1 个最关键的差异（颜色或标注），其余数据降为灰色。
5. 26–30s 来源与落版：数据来源、统计口径、日期常驻画面底部，结尾静止 ≥ 1.5s。

## 视觉规则
- 每个数字都来自用户提供的数据（表格、报告、截图）；没有数据就停下来问，不估算、不补全、不四舍五入成"更好看"的数。
- 柱状图从 0 基线开始生长；纵轴不截断。确需截断时画出断轴符号并在画面上说明。
- count-up 最后一帧必须是确切值（含小数位与千分位格式），用 `font-variant-numeric: tabular-nums` 防止数字跳宽。
- 单位、时间范围、来源说明在图表出现时同时可见，字号 ≥ 24px（1080p）。
- 一个主色表示"重点系列"，其余系列用中性灰；全片 ≤ 3 种数据色。
- 折线用 SVG path 绘制（stroke-dashoffset 从全长到 0），数据点坐标按数据线性映射计算，不手摆。
- 字体：默认 Noto Sans CJK SC / Roboto（数字），或用户提供的字体文件（放进 `assets/`）。
- 横屏：图表区占画面 60–70%，四边留 ≥ 96px 边距；字幕带（y 880–1060）不放关键数字。

## 制作路线
1. 先把用户数据整理成一张表写进 CANVAS.md：数值、单位、时间、来源、口径；每个画面数字对应表中一行。
2. 有配音（用户选择时）：`generate_file(kind="audio")`（purpose 为 narration）→ `normalize_audio_loudness`（−16 LUFS）→ `probe_media`；数字出现时间对齐语音。无配音：音乐床 `search_free_music` → `import_free_music` → `normalize_audio_loudness`，按 BPM 计算节拍网格，数据点落拍出现。
3. 用 `video_edit`（HyperFrames）构建：音频经 `video_edit(operation="push_assets")` 进项目、单位增益放置；坐标由数据计算；count-up 不能在 onUpdate 里写文字（部分引擎 seek 会抑制回调，画面停在旧值）：在 `hf-seek` 监听器里按 event.detail.time 用公式算出显示值（缓动用 gsap.parseEase 取与动画相同的曲线，再按精度取整），计数结束后显示确切值。
4. 全部动画在一条 paused timeline 上，是时间 t 的纯函数；不用实时时钟、不用无种子随机。
5. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取每个数字落定后的时刻，逐一核对数据表；批准后只用返回的 `review_sha256` 渲染。
6. 成片 MP4 用 `probe_media`、`render_frame_samples`、`analyze_audio` 验收。

## 已知坑
- count-up 停在 99.8% 处：缓动结束帧没写回确切值，或渲染帧恰好错过终点。
- 数字滚动途中出现无意义值（负数、超过终值）：用 `back` / `elastic` 缓动造成过冲，计数类不用过冲缓动。
- 柱子从中间长出来或基线不是 0：视觉上夸大差异。
- 百分比与绝对值混在同一坐标轴。
- 来源只在最后一秒出现：截图传播时来源丢失。

## 验收清单
- [ ] `probe_media`：1920×1080、30fps、时长与 CANVAS 一致。
- [ ] 成片中每个数字落定后的帧（`render_frame_samples`），数值与 CANVAS 数据表逐一一致（含单位与小数位）。
- [ ] 目视判断柱状图落定帧：所有柱子底边在同一 0 基线上。
- [ ] 每个图表落定帧都能读到单位与来源说明。
- [ ] 同一组帧中没有数据表之外的数字。
- [ ] 最后 1.5s 两帧静止一致，包含来源与口径。
- [ ] 有配音：`transcribe_video` 里念到的数字与画面数字一致。
- [ ] `analyze_audio`（成片 MP4）：整合响度在 −20 到 −14 LUFS，true peak ≤ −1 dBTP。
