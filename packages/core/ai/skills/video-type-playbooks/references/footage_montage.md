# 素材混剪卡点（Footage montage）

适用：把多段用户素材按音乐节拍剪成一支混剪（城市、活动、旅行、品牌 sizzle），统一调色和动态标题。默认：16:9、45s、无配音。

## 结构与节拍
45s 用 12–16 段素材，按一条时间或情绪弧线排列（样片：黎明天际线 → 早高峰人流 / 地铁 → 咖啡与手部特写 → 午间街头 → 黄金时刻 → 霓虹夜景延时 → 深夜安静街道）：
1. 0–3s 冷开场：一个最强画面 + 片名。
2. 3–40s 主体：每段 1–4 拍；能量高的段落 1 拍一切，舒缓段落 4 拍一切；每 8 小节安排一次 whip 或匹配剪辑。
3. 节拍点上的强调：推近 / 拉出（punch-in / punch-out）、速度变化。
4. 40–45s 落版：片尾标题卡，静止 ≥ 1.5s，音乐收尾。

## 视觉规则
- 一套调色贯穿所有片段：先定一个参考镜头，其他镜头的白平衡、对比、饱和向它靠拢。
- 动态字幕（kinetic captions）：粗体无衬线 + 一个 mono 小字，默认沙箱已安装的 Roboto Bold + Liberation Mono，或用户提供的字体文件（放进 `assets/`）；例如时间戳"06:12""08:45"随时间推进。
- Whip 转场：方向模糊峰值落在剪辑点上，前后两个镜头运动方向一致。
- 推近幅度 1.1–1.3 倍，硬切进入；1080p 素材不要放大超过 1.3 倍。
- 字幕与标题在 1080p 下留出 ≥ 96px 边距；竖版输出时文字避开 1080×1920 的上 220px、下 400px、右 140px。
- 画面中不出现可识别的第三方品牌 Logo 或商标。

## 制作路线
1. 素材：用户上传的视频（必填）。`probe_media` 每段的分辨率、帧率、时长；`render_frame_samples` 抽原素材帧挑选可用区间。没有 HDR 转换工具：请用户提供 SDR 导出，或排除 HLG / HDR 素材。
2. 音乐：用户提供或 `search_free_music` → `import_free_music` → `normalize_audio_loudness`（例：−16 LUFS）；记录 BPM，按 BPM 计算节拍网格，第一个重拍对齐冷开场后的第一刀。
3. 在 CANVAS 写 EDL：镜头 ID、源入出点、成片拍号、速度、转场。
4. 剪辑路线二选一，并写进 CANVAS：
   - Video Edit 路线（需要调色、推近、whip、动态字幕时）：在 `video_edit`（HyperFrames）中保留原素材文件，把入出点、速度、顺序、转场都作为可编辑图层表达；音乐与音效 stem 归一后 `video_edit(operation="push_assets")`、单位增益放置。全部是 paused timeline 上 t 的纯函数。
   - 原生路线（只需硬切 + 字幕 + 混音时）：`merge_videos` 的 clips 按入出点与速度裁切拼接（内部用 ffmpeg，传素材本身的 `aspect_ratio`）得到画面母版；再 `compose_video_timeline` 在这一条母版上混音、烧字幕并用 `loudness_normalization` 归一。`compose_video_timeline` 不负责剪辑。
5. 音效（whoosh、心跳重音）用 `generate_file(kind="audio")`（purpose 为 sfx）并归一，对齐转场。
6. Video Edit 路线审阅：`video_edit(operation="review", snapshot_times=[...])` 取每个剪辑点；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 计数 / 时间码字幕滚动时经过无意义的数值（如 06:12 → 06:97）：时间类计数按合法的时、分进位，或直接跳切，不做连续滚动。
- 素材里有可见的品牌 Logo、招牌、车标：换镜头、裁掉，或局部模糊。
- 调色不统一：白天、夜晚、室内镜头各一个色调，混剪显得拼凑。
- HDR 素材混入：颜色发灰或过饱和，Manor 不做色调映射。
- 剪辑点只"接近"节拍：偏 2–3 帧观众就能感到拖拍。

## 验收清单
- [ ] `probe_media`：分辨率、帧率、时长与 CANVAS 一致。
- [ ] 成片 5 个计划剪辑点各取 ±2 帧（`render_frame_samples`）：剪辑发生在节拍网格时刻（偏差 ≤ 1 帧）。
- [ ] 目视判断各段中点帧：整体色调一致（白平衡、对比无明显跳变）。
- [ ] 时间戳类字幕在同一组帧中的读数都是合法时间。
- [ ] 目视判断同一组帧：没有可识别的第三方品牌 Logo 或商标。
- [ ] 最后 1.5s 两帧静止一致，是落版标题卡。
- [ ] `analyze_audio`：音乐 stem 在目标 ±1 LU；成片 MP4 整合响度在 −20 到 −14 LUFS，true peak ≤ −1 dBTP，无意外静音。
