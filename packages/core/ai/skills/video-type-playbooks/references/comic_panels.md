# 漫画分镜（Comic panels）

适用：用分格漫画讲一个短故事或产品场景：镜头逐格推进，对话气泡逐个弹出，适合竖屏信息流。默认：9:16、30s、无配音。

## 结构与节拍
一页 4–6 格，30s 可做 1–2 页：
1. 0–2s 整页：整页漫画全景（首帧即可读出画风与主角），停 1–1.5s。
2. 2–26s 逐格：镜头推进到第 1 格 → 气泡逐个弹出 → 停留到能读完 → 平移到下一格。每格 3–5s，读完一个气泡至少 0.25s/字（中文）。
3. 关键格（转折 / 笑点）：可加一次放大冲击或速度线，只用一次。
4. 26–30s 回到整页或最后一格大图 + 标题 / 落款，静止 ≥ 1.5s。

## 视觉规则
- 分格网格：外边距 ≥ 48px，格间留白（gutter）16–24px，格框线宽统一（4–6px，黑色）。
- 镜头格到格移动：对整页容器做 transform（平移 + 缩放），0.6–0.9s `power2.inOut`；目标格放大到占画面宽 ≥ 85%。
- 对话气泡是可编辑的 SVG / HTML 文字（不画进生成图）：白底黑边，尾巴指向说话人嘴部；字体默认沙箱已安装的 Noto Sans CJK SC Bold，或用户提供的漫画字体文件（放进 `assets/`）；字号 ≥ 40px（1080 宽）。
- 角色一致：先定角色设定图（正面、侧面、表情 3 种），每格都以它为参照；发型、服装、配色不变。
- 9:16 安全区：气泡与标题避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520），镜头推进时同样适用。
- 画风全片一致（线稿粗细、上色方式、网点）。

## 制作路线
1. 剧本：按用户 brief 写分格脚本（格号、画面、台词、时长），台词由用户确认；写进 CANVAS。
2. 角色设定图：`generate_image` 先生成角色设定图；之后每格 `generate_image` 都带同一风格后缀，并在支持参考图时传入设定图；prompt 写明"无文字、无对话框"。
3. 逐格检查：逐张查看生成图，角色走样就重生成，记录用掉的次数。
4. 在 `video_edit`（HyperFrames）中排整页网格、气泡（SVG + 文本）和镜头路径；全部是 paused timeline 上 t 的纯函数。
5. 音效（翻页、弹出、冲击）用 `generate_file(kind="audio")`（purpose 为 sfx）；音乐用 `search_free_music` → `import_free_music`。各 stem 先 `normalize_audio_loudness`（音乐 −18 LUFS、音效按需），再 `video_edit(operation="push_assets")`，单位增益放置。
6. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取整页、每格气泡全部出现后的时刻、最后一帧；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 生成图里自带气泡或乱码文字：prompt 明确"无文字、无对话框"，逐张检查。
- 角色每格长得不一样：没有设定图参照、或风格后缀不同。
- 气泡停留时间不够，观众读不完就切走。
- 镜头推进时气泡跑出安全区或被裁切。
- 格框线粗细、颜色在不同格不一致（有的画在生成图里，有的是 SVG）：格框统一由 SVG 绘制，生成图只填格内画面。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps，时长与 CANVAS 一致。
- [ ] 成片 t=0 帧（`render_frame_samples`）为整页全景，画风可辨。
- [ ] 目视判断每格一帧：角色发型、服装、配色与设定图一致。
- [ ] 每格气泡全部出现后的帧：气泡文字与 CANVAS 台词逐字一致，且在 x 60–940、y 220–1520 内。
- [ ] 目视判断同一组帧：生成图内没有自带文字或气泡。
- [ ] 每个气泡的停留时长 ≥ 字数 × 0.25s（对照时间线）。
- [ ] 最后 1.5s 两帧静止一致。
- [ ] `analyze_audio`：音乐 stem 在目标 ±1 LU；成片 MP4 true peak ≤ −1 dBTP。
