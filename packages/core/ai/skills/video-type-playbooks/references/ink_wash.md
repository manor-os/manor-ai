# 国风水墨 / 工笔（Ink wash）

适用：节日海报、品牌国风短片、诗词意境：水墨笔触逐笔绘出，大面积留白，朱红印章与书法标题收尾。默认：9:16、20s、无配音。

## 结构与节拍
1. 0–2s 宣纸：纸纹底 + 第一笔已落下（首帧不是空白）。
2. 2–12s 逐笔成画：主体（山、竹、鱼、梅、器物）按笔顺绘出，每一笔 0.4–1.2s；笔与笔之间留 0.1–0.3s 的"提笔"停顿；墨色由浓到淡分层出现。
3. 12–16s 书法标题：标题逐笔写出（按笔顺），竖排放在留白处。
4. 16–18s 落印：朱红印章盖下（轻微缩放 1.05 → 1.0 + 一声闷响）。
5. 18–20s 静止：完整画面保持 ≥ 1.5s。
有音乐时，主要落笔对齐乐句的起点，而不是每一拍。

## 视觉规则
- 留白 ≥ 画面面积的 40%；主体偏置于三分线，不居中堆满。
- 笔触有粗细变化：不用等宽 stroke，而是用填充的笔画外形 + 沿笔画中线移动的遮罩揭示（起笔重、行笔细、收笔有飞白）。每一笔的外形与中线遮罩路径都需手工编写。
- 墨色 3–4 个层级（焦、浓、淡、清），只用墨色 + 一个朱红（印章与少量点景）；可加极淡赭石或花青。
- 纸纹：宣纸纹理用 SVG feTurbulence 生成，固定种子；墨的晕染边缘用 feTurbulence + feDisplacementMap 轻微扰动。
- 书法标题：字形来自用户提供的书法字体文件（放进 `assets/`）或书法字 SVG；字体轮廓不带笔顺，逐笔写出必须按正确笔顺为每一笔手工编写中线遮罩路径。没有书法字体时用沙箱已安装的 Noto Serif CJK SC 做整字揭示，不冒充手写。竖排，字距宽松。
- 9:16 安全区：标题与印章避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520）。
- 运动克制：镜头只做极慢的推或平移，不做弹跳、旋转、粒子爆炸。

## 制作路线
1. 题材与文字（诗句、标题、落款）只用用户提供的；引用古诗时核对原文与作者。
2. 画面：在 `video_edit`（HyperFrames）中以 SVG 绘制笔画；复杂主体可先用 `generate_image` 生成一张水墨参考图（标注为生成），再按其构图手工描成 SVG 笔画分层。
3. 书法：按字的笔顺拆分笔画，为每一笔写中线遮罩路径，逐笔揭示；字体缺字时换字或改为整字揭示并说明。
4. 音乐：`search_free_music` → `import_free_music`，选古琴 / 古筝风格、许可为可商用的曲目；或 `generate_file(kind="audio")`（purpose 为 music，写明古琴 / 古筝、慢板）。印章闷响用 `generate_file(kind="audio")`（purpose 为 sfx）。各 stem 先 `normalize_audio_loudness`（音乐 −18 LUFS、闷响按需），再 `video_edit(operation="push_assets")`，单位增益放置。
5. 所有笔画揭示、晕染、镜头运动挂在一条 paused timeline 上，是 t 的纯函数；纹理与扰动用固定种子。
6. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取首帧、成画中途、标题写完、落印后；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 等宽描边动画看起来像矢量图标，不像毛笔。
- 用字体轮廓做描边动画：轮廓没有笔顺，写出来的顺序是乱的。
- 留白被标题、Logo、二维码塞满，失去意境。
- 印章颜色偏橙或过饱和；朱红应偏深（接近朱砂色），印面有残缺纹理。
- 书法笔顺错误（例："火"先写中间一笔）：懂书法的观众会注意到。
- 音乐许可不清的"国风"曲目：只用 `import_free_music` 通过许可检查的曲目或生成的曲目。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps，时长与 CANVAS 一致。
- [ ] 成片 t=0 帧（`render_frame_samples`）可见纸纹与第一笔。
- [ ] 目视判断成画中途帧：笔画有粗细变化，不是等宽线。
- [ ] 标题书写中途取 3 帧：已出现的笔画符合正确笔顺。
- [ ] 目视判断最后一帧：留白约占 40% 以上，有朱红印章与书法标题；颜色只有墨色层级 + 朱红（+ 至多一种淡彩）。
- [ ] 标题、诗句与用户提供的原文逐字一致。
- [ ] 同一组帧中文字都在 x 60–940、y 220–1520 内；最后 1.5s 两帧静止一致。
- [ ] `analyze_audio`：音乐 stem 在目标 ±1 LU；成片 MP4 true peak ≤ −1 dBTP。
