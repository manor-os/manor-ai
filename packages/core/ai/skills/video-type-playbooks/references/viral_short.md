# 爆款短视频（Viral short）

适用：抖音 / 视频号 / 小红书信息流里的 12–18 秒短视频：第一帧钩子、一个爽点、ASMR 音效、手机实拍质感，不是宣传片。默认：9:16、15s、无配音。

## 结构与节拍
时长 12–18s。调研依据（立项时的 B 站调研，只用来定节奏，不写进画面）：设备类爆款多是 10–30s 的原始过程演示，例如制冰机约 301 万播放、炒菜机器人约 174 万播放。
1. 第 1 帧（t=0）钩子：大字钩子已在画面上，反常识或 POV 口吻（例："服务员只做了一个动作👆"、"最后这杯不是服务员调的"）。
2. 0.5–3s 起：动作开始，钩子缩小成标题留在上方。
3. 3–10s 过程：2–4 个过程镜头（伸手、点按、落冰），每个 1–2.5s，点按处快速推近。
4. 爽点（一个）：倒满 / 落冰 / 完成，用速度变化强化（例：0.5x 慢放渐变到 1x），落在音乐重拍上。
5. 最后 1.7–2.3s：品牌落版（纯色 + Logo，可加一句标语）。
剪辑点全部落在音乐节拍网格上（样片：每 6 拍一切，三联屏 4 拍，点按 2 拍，倒入 4 拍，落版 6 拍）。

## 视觉规则
- 手机原生质感：不加黑边、不做重调色，只做轻微锐化和提亮；整画面加带种子的手持微抖（正弦叠加，约 ±8px / ±0.3°，是 t 的纯函数）。
- 只用硬切 + 点按 / 重拍上的快速推近。
- 抖音原生字幕：粗黑体（默认沙箱已安装的 Noto Sans CJK SC Bold，或用户提供的字体文件），白字 + 约 14px 黑色描边 + 硬投影，关键词黄色；次级字幕放在倾斜的黄底框里；落冰时可弹出拟声字（"叮"）。
- 9:16 安全区：文字避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520）。
- 绝不伪造平台 UI（点赞栏、评论、直播间、"已售 10w+"）。
- 画面由 AI 生成时，全程在左下角安全区内标注"画面为演示效果"（y≈1462）。

## 制作路线
1. 素材：强烈优先用户的真实手机实拍（慢动作镜头用 60fps 以上）；无素材时用 `plan_video_segments` → `generate_video` → `wait_media_jobs` 生成并标注"画面为演示效果"。把每个镜头设计成可替换的"素材槽"（镜头 ID + 入点 + 速度），用户日后换成实拍即可重渲染。
2. 变速预处理（可选）：`merge_videos` 每段 clips 设入出点与速度（变速做成多段不同速度）；传入素材本身的画幅（竖拍传 `aspect_ratio` "9:16"），否则会按默认 16:9 缩小竖拍画面并加左右黑边。需要保留现场声时传 `include_source_audio` true。重构图与推近放到 Video Edit 里做。
3. 声音：默认无配音。ASMR 音效（点按、落冰、倾倒、碰杯）用 `generate_file(kind="audio")`（purpose 为 sfx）；一条轻快的音乐床用 `search_free_music` → `import_free_music`，选段让重拍落在爽点上。每条 stem 先 `normalize_audio_loudness`（例：音效 −16、音乐床 −20 LUFS），再 `video_edit(operation="push_assets")`，单位增益放置；落冰、倾倒处用音量自动化压低音乐。
4. 按 BPM 计算节拍网格，第一个重拍对齐爽点倒推；剪辑点写进 CANVAS。
5. 在 `video_edit`（HyperFrames）中合成：手持抖动、推近、字幕、标注都是 paused timeline 上 t 的纯函数，抖动用固定种子。
6. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取 t=0、每个剪辑点、爽点、最后一帧；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 第一帧是空镜或黑场：钩子必须在 t=0 就可读。
- 做成了宣传片：多个卖点、配音口播、精致调色，会被当成广告划走。只保留一个爽点。
- 钩子写成产品声明（速度、省人工、价格）而没有依据；"好解压"这类观众反应式文案可以，产品承诺不行。
- 生成画面里的动作和文案不符（例：文案说机器倒的，画面却是壶在桌边倒）：逐镜头核对。
- 音乐选段有长停顿，故事中间出现约 1s 空白。
- `merge_videos` 用默认画幅处理竖拍素材，竖拍画面被缩小并加左右黑边。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps，时长在 12–18s 之间。
- [ ] 成片 t=0 帧（`render_frame_samples`）可读出完整钩子文字。
- [ ] 目视判断成片各剪辑点帧：文字都在 x 60–940、y 220–1520 内，没有仿造的平台界面元素。
- [ ] 使用 AI 画面时，首、中、尾帧都能看到"画面为演示效果"。
- [ ] 目视判断同一组帧：无黑边；相邻两帧对比可见轻微手持位移。
- [ ] 目视判断爽点帧：爽点镜头存在且只有一个；最后一帧是品牌落版。
- [ ] `transcribe_video` 无人声口播（默认无配音时）。
- [ ] `analyze_audio`（成片 MP4）：整合响度在 −16 到 −13 LUFS（不达标时调整 stem 目标后重新渲染），true peak ≤ −1 dBTP，片中无超过 0.8s 的静音。
