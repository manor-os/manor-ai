# 等距剖面插画（Isometric cutaway）

适用：用等距视角的剖面插画展示一个空间或一条流程（门店后厨动线、设备内部、仓储物流），流程箭头随讲解流动。默认：16:9、30s、无配音。

## 结构与节拍
1. 0–3s 全景：完整的等距剖面建筑 / 设备已在画面上（首帧可读），轻微镜头推近。
2. 3–6s 分层揭示：外墙或外壳"切开"（剖面滑开或淡出），露出内部。
3. 6–24s 流程 3–5 步：每步高亮一个区域（其余降饱和），流程箭头沿路径流动到下一区域，标签随之出现；每步 3.5–5s。
4. 24–27s 全流程：所有箭头同时流动一遍，展示完整闭环。
5. 27–30s 标题 / 落款，静止 ≥ 1.5s。

## 视觉规则
- 真正的等距几何（30°）：所有物体用同一投影计算屏幕坐标，x' = (x − y) · cos30°，y' = (x + y) · sin30° − z；不手摆斜线。
- 三个面三个明度：顶面最亮、左面中、右面最暗，全片光照方向一致。
- 流程箭头：SVG 路径沿等距网格走向，用 stroke-dashoffset 做流动的虚线（速度恒定，是 t 的函数），箭头方向与流程一致。
- 标签锚定在物体上：标签坐标由该物体的 3D 坐标经同一投影算出，用引线连接；镜头推近时标签随物体移动，不漂浮。
- 调色板 5–7 色，一个高亮色只用于"当前步骤"。
- 标签字号 ≥ 24px（1080p），字体默认 Noto Sans CJK SC / Roboto，或用户提供的字体文件；四边留 ≥ 80px 边距；竖版输出时文字避开 1080×1920 的上 220px、下 400px、右 140px。

## 制作路线
1. 内容：流程步骤、区域名称、设备部件名称只用用户提供的；不清楚的流程先问，不自行补步骤。
2. 在 CANVAS 写一张"场景坐标表"：每个物体的 3D 尺寸与位置、每步高亮的物体、箭头的路径点。
3. 在 `video_edit`（HyperFrames）中用 SVG 按投影公式生成几何（多边形顶点由函数计算），剖面揭示用 clip-path 或图层透明度；所有动画在 paused timeline 上，是 t 的纯函数。
4. 需要真实感细节（设备外观）时，可用 `generate_image` 生成等距参考图（标注为生成），再按其外形用 SVG 重建，不直接贴生成图。
5. 有配音时（用户选择）：`generate_file(kind="audio")`（purpose 为 narration）→ `probe_media` 测实测时长 → `normalize_audio_loudness`（`target_lufs` −16，`target_duration_seconds` 取实测时长或该画面块计划容纳的时长；该参数会做时间伸缩，默认取实测时长，只有有意重新定时才用计划时长，且速度变化保持很小）→ `build_narration_timeline`（默认 `require_normalized_segments` 为 true，只接受带正值 `target_duration_seconds` 回执的归一化输出；分段语音何时用它见 video-production 的 references/production-and-edit.md 第 3 步），每步高亮对齐对应台词。无配音：`search_free_music` → `import_free_music` → `normalize_audio_loudness`（例：−18 LUFS），步骤切换落在乐句上。stem 经 `video_edit(operation="push_assets")` 进项目、单位增益放置。
6. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取每一步高亮时刻；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- "看起来像等距"但角度不一：某些物体用了 26.57°（2:1 像素等距）而其他用 30°，拼在一起错位。
- 标签漂浮：标签写死屏幕坐标，镜头一推就和物体分离。
- 流程箭头穿墙或从物体背后穿出：路径点没按遮挡关系排序。
- 高亮色被用作装饰色，观众分不清哪个是当前步骤。
- 剖面切开后内部空无一物或过度拥挤。

## 验收清单
- [ ] `probe_media`：分辨率、帧率、时长与 CANVAS 一致。
- [ ] 成片 t=0 帧（`render_frame_samples`）可读出完整剖面。
- [ ] 目视判断全景帧：所有物体的斜边角度一致（同一投影）。
- [ ] 每步高亮帧：只有一个区域使用高亮色，标签文字与 CANVAS 步骤一致。
- [ ] 推近过程中相隔 0.5s 的两帧：标签相对其物体的位置不变。
- [ ] 目视判断每步高亮帧：流程箭头方向与 CANVAS 流程顺序一致。
- [ ] 最后 1.5s 两帧静止一致。
- [ ] `analyze_audio`：各 stem 在目标 ±1 LU；成片 MP4 true peak ≤ −1 dBTP。
