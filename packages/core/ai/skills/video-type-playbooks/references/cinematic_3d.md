# 3D 场景（Cinematic 3D）

适用：无旁白的程序化 3D 电影短片：一个场景、电影镜头语言、宽银幕、时间（天色）推进，例如"风暴中的最后一座灯塔"。默认：16:9、40s、无配音。

## 结构与节拍
40s 参考（样片实测）：一个连续长镜头 + 一次硬切到终场全景：
1. 0–10s 低空推进：贴着海面 / 地面慢速推向主体，天色为黄金黄昏。
2. 10–20s 环绕：绕主体半圈，天色转入蓝调时刻，天气开始变化（雾、雨）。
3. 20–29.6s 升起揭示：镜头升起，看到主体的光（灯塔光束）扫过全景；高潮处一次远处闪电，雷声对齐闪电（样片：雷声裂响 25.55s 对齐 25.6s 的主闪电）。
4. 29.6–40s 硬切终场全景：风暴散去，星空，优雅衬线体标题淡入，静止 ≥ 2s 后淡出。
时间推进弧线：黄昏 → 蓝调 → 夜晚星空，每个阶段的光色在 CANVAS 写明。

## 视觉规则
- 宽银幕：16:9 画面内加 2.39:1 遮幅，1920×1080 下上下黑边各约 138px；标题放在画面区内。
- 后期：细颗粒（每帧种子不同但可复现）、暗角，在同一渲染管线内完成，与 3D 画面同一色调映射。
- 镜头语言克制：慢推、慢环绕、慢升，速度用缓入缓出，不做手持抖动；一次硬切。
- 光是主角：主光源（光束、窗光）在每个镜头都可见，天空色随时间渐变。
- 标题：一个优雅衬线体，默认沙箱已安装的 Noto Serif / Caladea，或用户提供的字体文件（放进 `assets/`）；字距略宽，不加特效。
- 闪电 / 闪光：亮度峰值持续 ≤ 3 帧，之后衰减，不出现整屏纯白。

## 制作路线
1. 场景与情绪按用户 brief；在 CANVAS 写镜头路径（关键帧时间、相机位置、目标点）与时间推进表。
2. 在 `video_edit`（HyperFrames）中实现 3D：每一帧完全由 seek 时间 t 决定（相机、天空、海浪、雨、闪电都是 t 的函数），不用 requestAnimationFrame 时钟；噪声与雨滴用固定种子。
3. 3D 运行库必须是本地文件：Three.js 须是 Knowledge 中已有的文件，经 `video_edit(operation="push_assets")` 暂存到 `assets/references/…`，并按返回的 `project_path` 原样引用（重名时文件会被改名；不要放进 `assets/vendor/`，该目录不随项目同步、也不计入 `review_sha256`；沙箱只预置 GSAP，不能从 CDN 加载）；没有可用的 Three.js 文件时，改用 Canvas 2D / CSS 3D 分层做 2.5D 场景（分层视差 + 光效），并在 CANVAS 写明。
4. 预览与渲染预算：先 `video_edit(operation="review", snapshot_times=[...])` 取 5–6 个关键时刻（含闪电前后）检查画面，并记录审阅耗时，据此决定粒子数量与后期复杂度；用户批准后只用返回的 `review_sha256` 渲染，渲染时间按审阅耗时估算并留足余量。
5. 声音：环境声（海浪、风、雨）、音乐垫、雷声用 `generate_file(kind="audio")`（purpose 分别为 ambience / music / sfx），音乐也可 `search_free_music` → `import_free_music`。各 stem 先 `normalize_audio_loudness`（例：环境 −24、音乐 −20、雷声按需），再 `video_edit(operation="push_assets")`，单位增益放置；雷声对齐闪电帧。
6. 成片 MP4 用 `probe_media`、`render_frame_samples`、`analyze_audio` 验收。

## 已知坑
- CDN 依赖：从网络加载 Three.js 在沙箱渲染时失败或结果不确定；只用经 push_assets 暂存的本地文件。
- 闪电白屏：闪光帧整屏过曝，持续多帧，既难看又不利于光敏观众。
- 渲染很慢：体积雾、大量雨滴粒子和全屏后期会让每帧耗时成倍增加；先看审阅耗时，留足渲染时间预算。
- 用 rAF 或实时时钟驱动动画：审阅帧与成片帧不一致，seek 后画面跳变。
- 遮幅黑边内放了文字，或遮幅高度在不同镜头不一致。

## 验收清单
- [ ] `probe_media`：1920×1080、30fps，时长与 CANVAS 一致。
- [ ] 目视判断成片 4 帧（`render_frame_samples` 取 0s、12s、24s、35s）：上下黑边高度一致（约 138px），天色依次为黄昏、蓝调、夜晚风暴、星空。
- [ ] 在计划闪电时刻 ±5 帧逐帧抽取（11 帧，单次 ≤ 24）：接近纯白的画面不超过 3 帧。
- [ ] 目视判断终场帧：可见颗粒与暗角；标题在画面区内，最后 2s 两帧静止一致。
- [ ] 审阅帧与成片同一时刻的帧画面一致（确定性）。
- [ ] 雷声 stem 在时间线上的起点与 CANVAS 闪电帧时间差 ≤ 0.1s。
- [ ] `analyze_audio`：各 stem 在目标 ±1 LU；成片 MP4 整合响度在 −20 到 −14 LUFS，true peak ≤ −1 dBTP，无意外静音。
