# 口播包装（Talking-head package）

适用：把用户已有的口播、访谈、讲解视频剪成可发布的成片：去掉废话、逐词字幕、口播触发的手绘批注、推镜，按平台画幅重构图；原片画面不重新生成。默认：9:16、45s、无配音（声音来自原片）。

## 结构与节拍
1. 0–4s 开场：一句最有钩子的原话（从全文中挑），可先放 0.5–1s 的 B-roll 再进人。
2. 中段 4–6 个片段：每段是一句完整的话，段与段硬切（jump cut）；每段 3–9s。
3. 每段 1 个批注点：说到关键词时，批注出现（圈词、箭头、便签、涂鸦），停留到该句结束。
4. 结尾：一句收束的原话 + 一个自然的结束动作（挥手、点头），最后画面停留 ≥ 1s。
样片参考：从约 210s 原片中取 7 段（共 41.3s），源区间逐段记录在 CANVAS（源入点 → 源出点、成片入点 → 出点、内容）。

## 视觉规则
- 字幕：衬线体逐词字幕（默认沙箱已安装的 Noto Serif CJK SC / Caladea，或用户提供的字体文件），当前词实色，后面即将出现的词淡显（约 35% 不透明度）；一屏 ≤ 2 行。
- 批注：SVG 手绘线条（圈、下划线、箭头、便签）用描边绘出动画；批注文字若要"手写出来"，字体轮廓不带笔顺，需为每一笔手工编写遮罩路径，否则用擦除揭示。手写体只用用户提供的字体文件。颜色 1–2 个，与字幕区分。
- 重构图：16:9 原片转 9:16 时以人脸为中心裁切；人物移动时人工设定重构图关键帧（每次明显移动设一帧），关键帧间平滑插值。
- 推镜（punch-in）只在强调句上用，放大 1.1–1.25 倍，硬切进入，不做缓慢推拉。
- 9:16 安全区：字幕与批注避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520）；字幕不压住嘴部。
- 原片中的台标、角标、原有下三分之一字幕不复用；需要署名时用简洁的 credit 行（例："素材：NASA（公有领域）"）。

## 制作路线
1. `probe_media` 原片（分辨率、帧率、时长、音轨）；`render_frame_samples` 抽原片帧了解构图与人物位置（原片是已存在的视频）。
2. `transcribe_video` 取得带时间戳的全文（超过 30 分钟分窗）；有用户提供的文稿或字幕时，以其文字为准校正。词级时间：分段时间戳内按字数比例插值，再在剪辑点附近人工核对。返回 timestamps_available=false 时，剪辑点改为按试听人工标注。
3. 在 CANVAS 写 EDL：每段源入出点、成片入出点、该段的批注词和推镜点。
4. 剪辑首选在 `video_edit`（HyperFrames）中保留原片，以 `data-media-start` 等图层属性表达入点；原片音轨随画面保留。若改用 `merge_videos` 先拼接，必须传 `include_source_audio` true（默认会丢弃原声），并传原片自身的画幅（16:9 原片传 `aspect_ratio` "16:9"），9:16 重构图再在 Video Edit 中做。
5. 在 `video_edit` 中做重构图关键帧、逐词字幕、批注与推镜，全部是 paused timeline 上 t 的纯函数。
6. 声音只用原片音轨（`normalize_audio_loudness` 只处理音频文件，不能直接归一视频里的原声）。成片响度不合适时，把渲染好的 MP4 作为 `clean_video_path` 交给 `compose_video_timeline`，传 `include_source_audio` true 与 `loudness_normalization`（例：target_lufs −16、true_peak −1.5）做最终两遍 loudnorm，输出新的成片。
7. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取每个剪辑点前后与每个批注出现时刻；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 原声丢失：`merge_videos` 默认 `include_source_audio` 为 false，拼接后的片子没有说话声。
- 画幅被压缩：`merge_videos` 默认 16:9 并按比例缩小加黑边，直接传 9:16 会得到带黑边的小画面。
- 放大发软：原片分辨率不足时推镜或 16:9 → 9:16 裁切会明显发糊；放大倍数控制在原片分辨率允许范围内，不够就减少推镜。
- 人脸漂移：没有自动人脸检测，人物侧移时脸跑出画面；每次明显移动都要补一个重构图关键帧。
- 剪辑点死寂：切点留了停顿或吸气，节奏拖沓；切点放在词与词之间，必要时音频比画面早几帧进（画面先停在首帧）。
- 转写错字直接上屏（专有名词、呼号、数字）：必须对照文稿校正。

## 验收清单
- [ ] `probe_media`：1080×1920（或平台画幅）、帧率与原片一致、有音轨，时长与 EDL 合计一致。
- [ ] `transcribe_video`（成片）文本与 CANVAS EDL 中各段文字一致，专有名词与文稿一致。
- [ ] 目视判断成片每个剪辑点前后帧（`render_frame_samples`，≤ 24 帧/次）：人脸完整在画面内且不压字幕，无黑边。
- [ ] 抽 3 处字幕：取 ±2s 窗口调用 `transcribe_video(input_path, start_seconds, end_seconds)`，插值词时间与画面高亮词时间偏差 ≤ 0.5s（timestamps_available=false 时标为"未测量"）。
- [ ] 每个批注出现时间不早于其关键词所在分段的语音开始。
- [ ] 目视判断同一组帧：没有原片的台标或原有下三分之一字幕。
- [ ] `analyze_audio`（成片 MP4）：整合响度 −16 ±1 LUFS，true peak ≤ −1.5 dBTP；剪辑点附近无超过 0.5s 的静音。
- [ ] 最后一帧停留 ≥ 1s，不是黑场或半句话。
