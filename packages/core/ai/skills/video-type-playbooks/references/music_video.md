# 音乐 MV（Music video）

适用：音乐驱动全部节奏的 MV：节拍网格、段落结构（intro / build / drop / outro）、随音频起伏的视觉，例如一支合成器浪潮风的"夜间驾驶"。默认：16:9、45s、无配音。

## 结构与节拍
先读曲子，再写画面。在 CANVAS 写曲目读谱：BPM、每段起止秒、drop 时间、重音位置。样片参考（129 BPM，48.6s 选段）：
1. 0–14s Intro / breakdown：稀疏、梦幻；主视觉世界缓慢展开，片名出现；5–8s 有一次情绪上扬。
2. 14–15s Build 末尾的"呼吸"：接近静音的一小节，画面收空，可做 3-2-1 倒数。
3. 15–45s Drop：每拍有反应（波形环、均衡条、路面速度）；drop 第一拍闪白 + 急推，曲名大字砸入；之后每小节一个短语，乐句转折处换色。
4. 45–48.6s Outro：鼓尾衰减，画面减速，落版并署名曲目。
剪辑与大动作落在重拍；小动作（闪烁、粒子）跟随包络。

## 视觉规则
- 每个段落一个配色族，段落切换时调色板在剪辑点 0ms 硬换。
- 主文字巨大（1080p ≥ 180px），放在暗部区域；HUD 小字 ≥ 26px，等宽、大写、宽字距。
- 字体：默认沙箱已安装的 Roboto Black（主文字）+ Liberation Mono（HUD），或用户提供的字体文件（放进 `assets/`）；不加载远程字体。
- 发光靠"宽低透明描边 + 细亮芯"双层描边，不靠投影。
- 不做彩虹循环；整屏纯白闪光 ≤ 3 帧（约 0.1s）。
- 文字不压在最亮的元素上（例：太阳圆盘）。
- 均衡条、波形环只在用户要求或风格需要时使用，数据来自预先写好的包络表。

## 制作路线
1. 音乐：用户上传的曲目优先（确认用户有权使用）；否则 `search_free_music` → `import_free_music`（选有真实 build 和 drop 的曲子），或 `generate_file(kind="audio")`（purpose 为 music，写明 BPM 与段落）。`probe_media` 得到时长。
2. 节拍网格：BPM 取自曲目信息或用户提供，按 60 / BPM 计算每拍时间，用 drop 第一拍校准偏移；小节线 = 拍号 % 4 == 0。段落边界人工听辨并写进 CANVAS。`analyze_audio` 的静音区间可帮助定位"呼吸"小节。
3. 包络表：没有自动音频特征提取工具；按节拍网格和段落强度预先写一张确定性的包络表（JSON：每拍的强度值，drop 高、breakdown 低），视觉只读这张表，不用实时 Web Audio。
4. 曲目先 `normalize_audio_loudness`（例：−14 LUFS、true peak −1），再 `video_edit(operation="push_assets")`，单位增益放置。
5. 在 `video_edit`（HyperFrames）中用一套共享的世界渲染（天空、路面、城市）贯穿各段，保证硬切前后世界连续；全部是 paused timeline 上 t 的纯函数，粒子用固定种子。
6. 落版署名：曲名、作者、来源与许可（`import_free_music` 返回的许可信息）。
7. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取每段首帧、drop 第一拍、落版；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- drop 闪白洗掉画面超过 3 帧：观众看到的是一片白，还可能触发光敏不适。
- 节拍网格偏移：BPM 正确但第一拍没对齐，所有动作慢半拍。
- 段落判断错误：把 build 当成 drop，视觉高潮来得太早。
- 用实时音频分析驱动画面：渲染时不可复现，审阅与成片不一致。
- 忘了署名曲目或许可。

## 验收清单
- [ ] `probe_media`：1920×1080、30fps，时长与选段一致（±0.1s）。
- [ ] 目视判断成片各段落首帧（`render_frame_samples`）：配色族与 CANVAS 段落表一致，段落切换处有调色板变化。
- [ ] drop 第一拍的帧：曲名大字出现；在 drop 第一拍 ±5 帧逐帧抽取（11 帧）：连续纯白不超过 3 帧。
- [ ] 抽 3 个计划重拍时刻：画面有对应的剪辑或冲击。
- [ ] 目视判断同一组帧：主文字不压在最亮元素上，HUD 小字清晰可读。
- [ ] 最后一帧署名包含曲名、作者与许可来源。
- [ ] `analyze_audio`：曲目 stem −14 ±1 LUFS；成片 MP4 true peak ≤ −1 dBTP。
