# 剪纸拼贴（Paper collage）

适用：手工感的短片：纸张质感、剪影分层、定格动画式的跳帧运动，适合节日、品牌故事和童趣内容。默认：9:16、20s、无配音。

## 结构与节拍
1. 0–2s 开场：桌面 / 纸面上已有一层剪纸元素（首帧有内容），第二层"啪"地落下。
2. 2–14s 3–4 个画面：每个画面由 3–5 层剪纸组成，层层落入或滑入；每层落位后有 1–2 帧的轻微回弹。
3. 换画面：用"纸翻页""撕纸""一张纸从上方盖过"等物理转场。
4. 14–18s 标题：标题字母 / 汉字作为单独剪纸块逐个落下。
5. 18–20s 静止：完整画面保持 ≥ 1.5s。

## 视觉规则
- 纸张质感：每层有纸纹（SVG feTurbulence 或生成的纸纹贴图），边缘略不规则（手剪感）；色纸 4–6 色，全片固定。
- 分层投影：每层一个小投影（偏移 4–8px、模糊 4–10px、不透明度 25–40%），越靠前的层投影越大，光源方向全片一致。
- 12fps 定格感：运动属性按 1/12s 量化（t_step = floor(t × 12) / 12），即每 2–3 个渲染帧更新一次位置；渲染仍是 30fps，不改输出帧率。
- 只有物体运动量化，镜头整体（如果有）保持平滑，或者干脆不动镜头。
- 标题字体：默认 Noto Sans CJK SC Bold / Lato Black，或用户提供的字体文件（放进 `assets/`）。
- 9:16 安全区：标题与文字避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520）。
- 剪纸块边缘清晰，不加柔光、不加景深模糊。

## 制作路线
1. 内容与文字按用户 brief；文字只用用户提供的。
2. 素材：剪纸元素优先用 SVG 绘制（形状 + 纸纹滤镜）；需要复杂图案时用 `generate_image` 生成"剪纸风、纯色背景、无文字"的元素图，全部带同一风格后缀，标注为生成。纸纹背景也可用 `generate_image` 生成一张。
3. 分层：生成元素在纯色背景上，进 Video Edit 后用 CSS mask / 手绘 SVG clip-path 取出（没有自动抠图工具）。
4. 在 `video_edit`（HyperFrames）中用 GSAP 制作落入、滑入、翻页；12fps 定格感用 `steps()` 缓动实现（例：1s 的位移用 steps(12)），或在 `hf-seek` 监听器中按 t 的公式量化（t12 = Math.floor(t × 12) / 12）；不要在 onUpdate 里量化，部分引擎 seek 会抑制回调。全部挂在 paused timeline 上，是 t 的纯函数，抖动用固定种子。
5. 声音：纸张摩擦、落下、翻页音效用 `generate_file(kind="audio")`（purpose 为 sfx）；音乐用 `search_free_music` → `import_free_music`（木琴、拨弦类）。各 stem 先 `normalize_audio_loudness`（音乐 −18 LUFS、音效按需），再 `video_edit(operation="push_assets")`，单位增益放置。
6. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取首帧、每个画面落定时刻、最后一帧；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 量化做在了输出帧率上（直接渲染 12fps）：平台转码后更卡，且音画不同步。
- 镜头和物体一起量化：整屏一顿一顿，看起来像掉帧而不是定格。
- 投影方向不一致或每层投影一样大：失去纸张层次。
- 生成元素纸纹各不相同、色彩超出色板。
- 层太多（> 6 层）导致画面杂乱。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps（输出帧率不是 12），时长与 CANVAS 一致。
- [ ] 成片一段运动中连续取 6 帧（`render_frame_samples`，间隔 1/30s）：物体位置呈 2–3 帧一变的阶梯状。
- [ ] 目视判断各画面落定帧：可见纸纹与分层投影，投影方向一致；颜色在 CANVAS 定义的色纸色板内。
- [ ] 成片 t=0 帧不是空白。
- [ ] 同一组帧中文字都在 x 60–940、y 220–1520 内，与用户提供的一致。
- [ ] 最后 1.5s 两帧静止一致。
- [ ] `analyze_audio`：音乐 stem 在目标 ±1 LU；成片 MP4 true peak ≤ −1 dBTP。
