# 动态金句 / 文字海报（Kinetic quote）

适用：一句话或一组金句的动态排版，文字本身就是画面，适合朋友圈、视频号、小红书。默认：9:16、15s、无配音。

## 结构与节拍
1. 0–0.5s 首帧：金句的第一个关键词已经在画面上（封面可读），不从空白开始。
2. 0.5–10s 逐词 / 逐短语出现：有配音时按语音时间出字；无配音时按音乐节拍出字（每 1–2 拍一个短语）。一屏最多 2 行、每行 ≤ 10 个汉字或 ≤ 5 个英文单词。
3. 关键词强调：全句只强调 1–2 个词（放大、换强调色或描边转实心），强调发生在该词被说出 / 落拍的那一刻。
4. 10–13.5s 最后一行：完整金句静止保持 ≥ 1.5s，不再有任何文字位移。
5. 13.5–15s 署名或出处（作者、品牌、来源）小字淡入；用户未给出处则不写。

## 视觉规则
- 最多 2 种字体：默认 Noto Sans CJK SC（粗）+ Noto Serif CJK SC，或用户提供的字体文件（放进 `assets/`）；不加载远程字体。
- 9:16 安全区：文字避开 1080×1920 的上 220px、下 400px、右 140px，即文字只放在 x 60–940、y 220–1520。
- 主字号：中文 display ≥ 96px，署名 ≥ 36px；文字与背景对比度 ≥ 4.5:1。
- 背景简单：纯色、缓慢渐变或一张低对比纹理；背景运动幅度小于文字运动。
- 动作语法统一：全片用一种入场（例：自下而上 mask reveal，`expo.out`，0.4–0.6s），强调用一种动作，不混用弹跳、旋转、打字机。
- 断行按语义：不把一个词或一个固定搭配拆到两行。

## 制作路线
1. 文本：只用用户给的金句原文，不改写；署名按用户提供。
2. 有配音：`generate_file(kind="audio")`（purpose 为 narration，指定 language 与 voice）→ `normalize_audio_loudness`（−16 LUFS）→ `probe_media` 测时长 → `transcribe_video` 取分段时间戳；段内逐词时间按字数比例插值，作为出字时间。返回 timestamps_available=false 时，按 `probe_media` 时长与停顿人工分配并在 CANVAS 标注"估算"。
3. 无配音：用户音乐或 `search_free_music` → `import_free_music`，`normalize_audio_loudness` 后使用；按 BPM 计算节拍网格，出字落在拍点上。
4. 用 `video_edit`（HyperFrames）排版：音频经 `video_edit(operation="push_assets")` 进项目、单位增益放置；每个词一个 span，所有动画挂在一条 paused timeline 上，是 t 的纯函数。
5. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取首帧、每次强调时刻、最后一行静止段首尾；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 字出得比说得早：观众先读完，配音变成重复。出字时间不得早于该词所在分段的语音开始。
- 最后一行刚出现就结束：留不够 1.5s 读完，转发率最差。
- 字体缺字：用户提供的书法类字体常缺生僻字，渲染成方框或回退字体；先用全文检查字形覆盖。
- 文字压到安全区外：平台的标题、按钮、评论区会盖住。
- 强调太多：每句都放大等于没有强调。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps、时长与 CANVAS 一致。
- [ ] 成片首帧（`render_frame_samples` t=0）可读出至少一个完整关键词。
- [ ] 目视判断成片的首帧、强调帧、末帧：文字都在 x 60–940、y 220–1520 内。
- [ ] 目视判断同一组帧：字体家族不超过 2 种，没有方框缺字。
- [ ] 最后一行完整出现后，相隔 1.5s 的两帧文字位置完全一致。
- [ ] 画面文字与用户提供的金句逐字一致（含署名）。
- [ ] 有配音：`transcribe_video` 文本与金句一致；对 2 个强调词各取 ±2s 窗口调用 `transcribe_video(input_path, start_seconds, end_seconds)`，由返回分段按字数插值得到的该词时间与画面强调时刻偏差 ≤ 0.5s（timestamps_available=false 时标为"未测量"并人工试听）。
- [ ] `analyze_audio`（成片 MP4）：整合响度在 −20 到 −14 LUFS，true peak ≤ −1 dBTP。
