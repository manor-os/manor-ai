# 餐厅 / 门店宣传片（Venue promo）

适用：餐厅、门店或空间的宣传片：真实美食与空间镜头 + 主视觉静帧 + 书法或动效标题，按音乐节拍剪辑，传达"烟火气"。默认：9:16、30s、有配音。

## 结构与节拍
弧线：街景 → 厨房火光 → 双手手艺 → 菜品主角 → 人们分享 → 品牌。30s 版参考（100 BPM，1 拍 0.6s，1 小节 2.4s；样片实测）：
1. 0–2.4s 夜街：火焰或霓虹开场，匹配剪辑（火焰 → 红色霓虹），HUD 小字打出时间地点。
2. 2.4–7.2s 厨房火：音乐 drop 落在锅气爆燃上；每 1–3 拍一切，速度变化（0.5x → 2.2x），书法字（如"火"）一拍一笔绘出。
3. 7.2–12s 手艺：拉面、包褶、摆盘微距；蒸汽中浮现"招牌"标题（模糊 → 清晰）。
4. 12–18s 菜品主角：每道菜一拍到一小节，主图做 2.5D 视差，菜名卡在拍点上砸入。
5. 18–24s 分享：筷子伸向同一盘菜、碰杯（配碰杯声），一句情绪标语擦入。
6. 24–30s 品牌：推向门头，店名书法逐笔绘出，最后的音乐重音上闪白并落版（Logo、地址、营业时间）。
60s 版是独立重剪：同一弧线，每段约翻倍，加菜单卡与室内镜头，不是 30s 的拉长。

## 视觉规则
- 一套暖调高反差调色应用到所有镜头（钨丝灯 / 炭火橙 + 深阴影，暗部微青）；每个镜头调色后再与相邻镜头对比亮度。
- 书法标题逐笔绘出：字体轮廓不带笔顺，必须为每一笔手工编写中线遮罩路径并按笔顺排列（例："火"4 笔 4 拍）；书法字形来自用户提供的书法字体文件或品牌字标 SVG。没有书法字体时用 Noto Serif CJK SC 做整字揭示，不冒充手写。
- 其他文字：默认 Noto Sans CJK SC（字幕）+ Liberation Mono（地址、时间），或用户提供的字体文件（放进 `assets/`）。
- 9:16 安全区：文字避开 1080×1920 的上 220px、下 400px、右 140px（文字区 x 60–940、y 220–1520）。
- 镜头内容只表现氛围与手艺：不出现评分、评价、奖项、"最好吃"、榜单。
- 虚构品牌在落版注明"虚构品牌 · 概念片"。

## 制作路线
1. 素材：真实门店素材优先（用户提供的菜品、厨房、空间、人物视频与照片）；用户未提供时，氛围镜头可用 `generate_video` / `generate_image` 生成并在 CANVAS 标注，菜品与门头必须以用户真实照片为准。`restaurant-promotion-video`（instructions_only）提供食物与场地一致性约束。
2. 素材色彩：没有 HDR 转换工具；请用户提供 SDR 导出的视频，或排除 HLG / HDR 素材。
3. 主图静帧：用户照片优先；需要生成时 `generate_image` 全部使用同一风格后缀，控制生成次数。视差前景用手绘柔边椭圆 × 亮度遮罩分层（暗底食物不适合自动抠图）。
4. 音乐：`search_free_music` → `import_free_music`，记录 BPM，按 BPM 计算节拍网格，drop 时间写进 CANVAS。
5. 剪辑：在 `video_edit`（HyperFrames）中保留原素材，入出点、速度、顺序作为可编辑图层表达。若先用 `merge_videos` 做变速分段，传素材本身的画幅（竖拍传 `aspect_ratio` "9:16"），需要现场声时传 `include_source_audio` true；重构图在 Video Edit 中完成。
6. 配音：`generate_file(kind="audio")`（purpose 为 narration）→ `normalize_audio_loudness`（−16 LUFS）；中文配音生成后用 `transcribe_video` 回听，确认可懂度；字幕按实测语音时间。音乐（−24 LUFS）与音效（滋滋声、火焰呼声、碰杯，`generate_file(kind="audio")` purpose 为 sfx）同样先归一，再 `video_edit(operation="push_assets")`，单位增益放置。
7. 在 Video Edit 中合成调色、书法、菜名卡、视差、字幕和混音；全部是 paused timeline 上 t 的纯函数。
8. 审阅：`video_edit(operation="review", snapshot_times=[...])` 取每段首帧、每个菜名卡、最后一帧；批准后只用返回的 `review_sha256` 渲染。

## 已知坑
- 火焰过曝：火光区域一片死白、失去层次；调色时压高光，检查火焰内部仍有橙黄过渡。
- 白天素材混进夜景调色：同一套暖调让白天镜头发灰发脏；只选夜间 / 室内镜头，或单独校正后再统一。
- HDR（HLG）素材颜色异常：Manor 不做色调映射，只用 SDR 素材。
- 用字体轮廓做"笔画动画"：笔顺是乱的，懂书法的观众一眼看出。
- 编造评价、奖项、排名或"必吃榜"：一律不写。
- 30s 版直接截 60s 的前半段：后半段的人物与品牌全丢了。

## 验收清单
- [ ] `probe_media`：1080×1920、30fps，时长与 CANVAS 一致。
- [ ] 目视判断成片各段首帧（`render_frame_samples`）：弧线顺序为 街景 → 火 → 手艺 → 菜品 → 分享 → 品牌。
- [ ] 抽 3 个计划剪辑点 ±2 帧：剪辑发生在 CANVAS 的节拍网格时刻（偏差 ≤ 1 帧）。
- [ ] 目视判断火焰镜头帧：火焰内部有颜色层次，不是大面积纯白。
- [ ] 目视判断同一组帧：文字都在 x 60–940、y 220–1520 内；没有评价、评分、奖项字样。
- [ ] 最后一帧落版的店名、地址、营业时间与用户提供一致；虚构品牌有"虚构品牌"说明。
- [ ] `transcribe_video` 文本与文稿一致，可懂度足以逐句转写。
- [ ] `analyze_audio`：配音 stem −16 ±1 LUFS、音乐 stem −24 ±1 LUFS；成片 MP4 true peak ≤ −1 dBTP。
