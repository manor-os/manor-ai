# Upstream Remotion plugin

This Manor bundle adapts the official OpenAI Remotion plugin version 1.0.7 and its 12 Skills. The Remotion packages are pinned to 4.0.506.

- Plugin: https://github.com/openai/plugins/tree/main/plugins/remotion
- Remotion Agent Skills: https://github.com/remotion-dev/skills
- Documentation: https://www.remotion.dev/docs/
- Repository and license: https://github.com/remotion-dev/remotion

Manor exposes local project creation, deterministic markup, captions, media inspection, still review, and local rendering through its isolated sandbox. Hosted rendering, user-visible Studio ports, paid external services, and licensing claims remain unavailable until separately connected and verified.
