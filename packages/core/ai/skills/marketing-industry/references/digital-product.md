# Digital product and SaaS marketing

## Buyer and offer

Separate a consumer app signup from a B2B operator evaluation. For B2B, identify the role that feels the problem, the buyer/approver, current workaround, implementation concern, and measurable desired outcome. For B2C, identify the immediate task and first useful moment. Choose an accurate CTA: try, sign up, request a demo, join a waitlist only if one exists, or read a product page.

Build a product truth pack from current UI/screenshots, docs, supported features and integrations, pricing/plan page, release state, security/compliance documents when relevant, customer permission for quotes, and the destination signup/demo flow. Do not turn roadmap items into shipped features. If the demo environment differs from production, label it. Never fabricate a customer logo, testimonial, benchmark, percentage improvement, or comparison.

| Stage | Buyer question | Useful proof | Content pattern |
| --- | --- | --- | --- |
| Problem discovery | Is this problem worth changing? | Specific workflow friction and real example | Explain the task and cost of the current process without invented numbers |
| Evaluation | Can the product do this now? | Accurate UI, step-by-step use case, limits and integrations | Demonstration with realistic input/output |
| Purchase approval | Is it worth adopting safely? | Verified plans, admin controls, support, security or case evidence | Comparison/checklist or demo follow-up |
| Activation | How do I reach value? | Onboarding steps and first useful result | Guided use-case content or welcome sequence |

## Creative and handoff

For a product promo, write the hook around a real task and demonstrate the product's actual state before making a benefit claim. Keep on-screen UI readable and consistent with current product design. Include source path/screenshot for each shown feature, exact wording for claims, CTA destination, and visual proof needed. A video script should state which frames require captured UI instead of AI-generated lookalikes; Video Production handles canvas and edit.

Measure qualified demo requests, signup-to-activation, trial use, or purchase according to the stage. Clicks alone do not show adoption. If baselines or analytics are absent, define an event to instrument and label expected effects as hypotheses.
