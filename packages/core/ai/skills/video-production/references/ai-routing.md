# Manor media-tool routing per shot

The script and source assets determine the method. Select a model only after identifying the required control and checking Manor's current tool schema, Account selection, and `video_model_capabilities` in `packages/core/constants/models.py`. Provider marketing pages do not prove that Manor's adapter exposes a control. These tool names are Manor's runtime tools, not external MCP substitutes.

| Shot need | Preferred method | AI/tool decision |
| --- | --- | --- |
| Supplied footage, exact UI, logo, real person/place/product, documentary evidence | Use the source or a new authorized capture | Keep its real Knowledge path/document ID and original source trim in the editable timeline; do not fabricate a replacement |
| Titles, diagrams, maps, captions, structured motion | Editable composition | Keep captions as timeline cues; use `video-edit` when the motion or layering exceeds the native compositor; do not bake critical text into AI footage |
| Style reference, matte, background, or required first/last keyframe | Still generation | `generate_image(prompt=..., name=..., reference_urls=[...])`; inspect its completed URL and composition before using it as a video control |
| New moving picture needed by a script shot | Short AI footage | `plan_video_segments` for the shot, then `generate_video` with its `expected_model`, supported references, planned duration and stable name; `wait_media_jobs` for the returned job ID |
| Narration, dialogue, music, ambience, Foley, SFX | Separate sound asset | `generate_file(kind="audio", prompt=..., name=..., params={"purpose": "narration|dialogue|music|ambience|sfx", ...})` or use a supplied recording; for a background bed when original-music credentials are missing, use Manor's `search_free_music` and `import_free_music`; keep stems separate for edit |
| Several minutes or longer | Scene/chapter assets plus editable master | Build multiple short clips and audio stems; save a timecoded EDL and compose chapter/film timelines with Manor tools |

Use only the roles the script needs. Search the Account-selected audio model for each needed purpose before calling `generate_file(kind="audio")`; narration, music, ambience, and SFX may have different routes. Report the actual model and route when the tool returns them; do not assume a named provider from an earlier run. A catalog music bed has a different provenance: retain its actual license and creator in the canvas, and include CC BY attribution in final credits. Its import requires edit access to the project's CANVAS.md Knowledge Document, so search and import before paid video work; this also catches a Knowledge storage quota blocker early. Generate each spoken cue from the exact script text, keep its speaker identity stable, and use `probe_media` to measure the completed audio before placing it on the timeline. `generate_video` returns `status="pending"` and a `job_id`, not a finished MP4. `wait_media_jobs(job_ids=[...])` may return `pending`, `failed`, or `completed`; use the completed output path/document receipt only after it is present. `probe_media(input_path=...)` verifies duration/streams. `render_frame_samples(input_path=..., output_dir="Videos/<project>/review/<shot-id>", timestamps=[...])` creates review frames from an actual Knowledge video. A filename proposed in a prompt is not proof of a saved file.

## Frame and duration controls

`plan_video_segments(target_duration_seconds=..., generation_mode="image_to_video"|"text_to_video")` returns the Account-selected `model`, provider `generation_durations_seconds`, and final `segment_durations_seconds`. The target accepts whole seconds and at most 3600 per call; plan each shot, not the complete film. For a fractional editorial shot, round the provider request up and trim the completed clip in `merge_videos` or Video Edit. If the selected model cannot take a required first frame, last frame, or reference, change the shot method or surface the specific model capability gap before spending on generation. Do not silently drop a requested control, change Account settings, or pass an undisclosed override.

Use the exact returned first/last keyframe URL or authorized Knowledge reference; never invent `/api/v1/fs/...` paths. If a shot depends on references, set `requires_reference_media=true` and include supported `first_frame_url`, `last_frame_url`, or `reference_urls` in the actual `generate_video` call. `expected_model=plan.model` detects an Account model change before paid work. Generate silent picture (`generate_audio=false`) when speech, music, and effects will be placed as editable stems. Keep one shot ID in every media filename and receipt.

For each AI shot, record actual model, prompt version, first/last/reference URLs passed, requested and measured durations, aspect ratio, job ID, completed asset path/document ID, rights status, and chosen take. Verify the generated output against the canvas. Reuse a completed job on retry; a provider submission may be billable. Stop on a real credential, quota, credit, permission, or unsupported-control blocker instead of repeatedly sending the same request.

If the user selects a specific connected provider, inspect its current Manor route and supported inputs before use. An external provider reference never overrides the registered Manor tool and Account capability contract.
