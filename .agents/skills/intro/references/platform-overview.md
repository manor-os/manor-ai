## What Manor AI is

Manor AI is a self-hosted AI workspace that connects conversations to persistent work. Users can organize a business or project, collaborate with AI Agents, manage Tasks, use Knowledge and documents, review approvals, and turn repeated processes into Flows and Automations.

The product is designed to keep context, execution, review points, and results together. This helps users move from a request to trackable work and a verifiable outcome.

The public edition is source-available under the Manor Sustainable Use License. This guide covers only the visible end-user product and does not provide deployment or infrastructure instructions.

## Core concepts

| Concept | What it represents |
| --- | --- |
| Workspace | A shared operating area for a business, project, client, or team |
| Goal | A measurable outcome that guides work |
| Task | An assignable and trackable unit of work |
| Plan and Step | The planned sequence and individual actions used to complete a Task |
| Agent | An AI work role configured for a specific responsibility |
| Tool | An action an Agent can perform |
| Skill | A reusable method, instruction set, or resource package |
| Integration | A connection to another application or communication channel |
| Knowledge | Documents and files that users and Agents can reference |
| Flow | A multi-step process with defined stages |
| Automation | A repeated or scheduled action |
| Approval | A point where a person reviews or decides before work continues |

## Capability map

### Chat and collaboration

- Use Manor AI for research, planning, drafting, and starting work.
- Use Workspace Chat when a request depends on Workspace goals, Knowledge, Rules, or Agents.
- Mention an Agent when the conversation supports directed collaboration.
- Select an available Skill from Chat Composer.
- Attach a local file or reference an existing Knowledge document.
- Review progress cards, requested approvals, and generated artifacts.
- Search and manage conversation history through visible controls.

### Workspaces

- Create a Workspace through the guided drafting experience.
- Define services, goals, members, Agents, Knowledge, Rules, channels, and Automations.
- Use Overview to understand status and progress.
- Use Configure to connect Staff, Agents, Capabilities, Channels, Knowledge, Rules, Goals, Automations, and Learning.
- Use Activity to follow important changes and execution progress.
- Use Settings for options available to the current user.

### Tasks

- Create organization-level or Workspace-level Tasks.
- Set priority, assignment, due time, schedule, attachments, and acceptance criteria.
- Use Board to track operational state.
- Use Calendar to review scheduled and due work.
- Review Plans, Steps, comments, progress, and artifacts in Task Detail.
- Respond when a Task requests approval or more input.
- Retry failed work through the visible retry action after correcting the cause.

### Agents

- Create an Agent for a defined role.
- Set its purpose, working instructions, Tools, and Skills.
- Test representative messages before regular use.
- Add the Agent to a Workspace service.
- Review visible execution history and results.
- Import or export an Agent when those actions are available.

### Skills

- Create a reusable Skill manually or with the guided builder.
- Import a trusted Skill package when import is available.
- Test a Skill with representative input.
- Add the Skill to selected Agents.
- Invoke an available Skill from Chat Composer.
- Review imported Skills before important use.

### Knowledge and documents

- Upload and organize files in folders.
- Create documents, AI-assisted drafts, and Wiki pages.
- Search, filter, favorite, move, share, download, and restore content when permitted.
- Add relevant content to a Workspace.
- Wait for processing to complete before relying on retrieval.
- Use Wiki Map to explore connected pages and missing links.

### Flows and Automations

- Build a Flow for a process with multiple stages.
- Use Agent, Tool, Condition, Wait, Notify, and Transform steps when shown.
- Test a Flow and review its result.
- Create recurring, interval-based, or one-time Automations.
- Run an Automation immediately for a controlled test.
- Review recent runs and confirm the expected result.

### Integrations and channels

- Browse Integration options shown in the current deployment.
- Follow the on-screen connection flow.
- Make a connected capability available to the intended Agent or Workspace.
- Connect supported communication channels.
- Route inbound conversations to the intended Workspace or Agent.
- Test with a small reversible action or test message.

### Reports, notifications, and search

- Use Dashboard for a high-level view of work and activity.
- Use Reports to review Tasks, usage, and activity when available.
- Use Notifications to follow assignments, approvals, and important events.
- Use Search to locate supported objects.
- Use Messages or Chat History to follow connected conversations when enabled.

### Account and Settings

- Update profile and appearance options.
- Set time-zone and calendar preferences.
- Review available AI model options.
- Review notification and file-action preferences.
- Use security controls presented to the current user.

## First workflow

1. Open Manor AI and send a short request.
2. Create a Workspace with a clear outcome.
3. Add a test document to Knowledge and wait until it is ready.
4. Create or select an Agent with the required Tool or Skill.
5. Add the Agent and document to the Workspace.
6. Create a small Task with a verifiable result.
7. Respond to any approval or input request.
8. Confirm the resulting artifact.

## Availability guidance

- Use the current screen as the authority for visible features.
- Optional capabilities depend on the deployed version, Workspace access, and connected applications.
- A connected application may still need to be added to the intended Agent or Workspace.
- A completed run should be verified through its visible result or artifact.
- An uploaded document may need processing time before it can be retrieved.
- Refer installation and infrastructure questions to the official Manor AI documentation.
